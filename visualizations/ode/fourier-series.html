Fourier series

Add rotating circles (sines) of frequency 1, 2, 3, … to build any periodic wave
Each circle is one term aₖ·sin(kt). More terms → closer to the target, but next to a jump the partial sums always overshoot by about 9% (the Gibbs phenomenon). The triangle wave has no jumps, so it converges much faster.

About the concept

Any reasonable periodic function can be written as a sum of sines and cosines with frequencies 1, 2, 3, …. Each coefficient measures how much of that frequency the function contains. Smooth functions need few terms; at a jump, partial sums always overshoot by about 9% (the Gibbs phenomenon).

f(t) = a0/2 + Σk≥1 (ak cos kt + bk sin kt),   bk = (1/π) ∫−ππ f(t) sin kt dt;   square wave = (4/π) Σk odd sin(kt)/k

Why it matters: Audio and image compression (MP3, JPEG), signal filtering and solving the heat and wave equations are all built on this idea.
