Pendulum phase space

θ″ = −sin θ − b·θ′ — every state (angle, angular velocity) is a point; motion follows the arrows
Tap the phase plane to start the pendulum there. Closed loops = swinging; wavy lines across the top/bottom = spinning over the top. The dashed separatrix divides them. Add damping b and every path spirals into a resting state θ = 0, ±2π.
